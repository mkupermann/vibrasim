# JEP-82 — substrate as the world-model PREDICTOR inside an MPC loop (MPC pillar on the substrate)

## Why
JEP-81 reconnected the substrate as an isolated EBM+predictor. This rung puts it INSIDE the planning loop: use
world.energy.EnergyNet's own predictive dynamics (asymmetric transition matrix + energy clean-up) as the
action-conditioned world-model that an MPC controller rolls forward to plan. The MPC pillar, executed on the
substrate.

## Setup
- K=8 discrete states arranged in a ring, each a random +/-1 pattern, stored as ATTRACTORS in EnergyNet (W, via
  contrastive-Hebbian train_epoch).
- Two actions: NEXT / PREV. Each gets a Hebbian asymmetric transition matrix (T_next, T_prev) over consecutive
  ring patterns. Prediction = substrate predict_step (tanh transition + energy clean-up to the nearest attractor).
- MPC: from a start state, at each step roll the substrate predictor for BOTH actions, pick the action whose
  predicted (cleaned) next state is closest (Hamming) to the goal pattern; apply; repeat up to K steps.

## Pre-registration (locked BEFORE run)
- (i) substrate predictor 1-step accuracy >= 0.95 (predict_step lands on the correct ring neighbour, cleaned).
- (ii) substrate-MPC reaches the EXACT goal pattern within K steps for >= 0.90 of all (start,goal) pairs.
- (iii) negative control: random-action policy reaches the goal within K steps for <= 0.5 of pairs (planning beats
  random). PASS = all three. Places the substrate as the world-model predictor in an MPC loop. Established
  (Hopfield attractor dynamics, model-predictive control), named; no novelty.

## Result — NULL (greedy planner brittle; substrate predictor is perfect)
- (i) substrate predictor 1-step accuracy = **1.000** (the substrate world-model is exact).
- (ii) greedy substrate-MPC goal-reach = 0.375 — BELOW the 0.90 bar.
- (iii) random-action control = 0.518 — greedy MPC is WORSE than random.

**VERDICT: NULL (planner, not substrate).** The substrate's predict_step is a perfect action-conditioned
world-model (1.00), but the GREEDY 1-step MPC fails: with random +/-1 state codes, Hamming distance to the goal
carries no ring-distance signal (all non-goal patterns are ~equidistant), so greedy has no gradient and only
succeeds when it stumbles adjacent to the goal. This reconfirms the programme's RECURRING lesson (JEP-8/9/15):
greedy 1-step planning is brittle; proper multi-step planning is required. The substrate is fine; the controller
was wrong. Fixed in JEP-82b with horizon planning THROUGH the substrate model. Honest NULL, not retuned.

**VERDICT: PASS.** The MPC pillar realized on world.energy.EnergyNet — the substrate is the world-model a proper
