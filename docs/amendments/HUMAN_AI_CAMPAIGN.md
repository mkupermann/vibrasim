# Campaign — "human-like AI on the substrate, no LLM" (step-by-step, try-and-error)

## The honest premise (read first)
This session and ~100 prior experiments established two hard facts:
1. The substrate is a competent MEMORY + I/O medium (matter-position memory G116–G129; co-located codec
   G104; driven-matter transport G113) — all no-LLM.
2. The substrate canNOT learn or compute on its own (spatial XOR NULL, temporal/reservoir NULL, no
   association sticks in its activity). It has no cognitive layer and cannot grow one from its dynamics.

So "human-like AI FROM the substrate's own intelligence" is not reachable — that is a settled negative,
not a thing more try-and-error will overturn. What IS reachable, and worth building step by step, is:
**a CLASSICAL no-LLM learner (established statistical ML — Hebbian/perceptron/VSA/reservoir/n-gram) that
uses the substrate's demonstrated primitives (position-memory as its weight/state store, codec as I/O).**
The "intelligence" lives in the classical algorithm; the substrate is the memory/peripheral. This is
"no LLM" in the strict sense (no transformer/pretrained/BPE) — but it is statistical ML producing
PLAUSIBLE language-like output, NOT human understanding. Every rung below names which part is the
classical algorithm and which is the substrate, so we never mistake the peripheral for a mind.

## The rungs (each a pre-registered experiment, honest PASS/NULL)
- **R1 — Selective persistent MEMORY.** DONE ✓ (matter-position, G116–G129; clean multi-bit, text).
- **R2 — Associative LEARNING + generalization (G132).** A classical linear/Hebbian associator learns
  A→B pairs and recalls B from NOISY/novel A. Establishes the learning engine is classical ML and runs
  with substrate-stored weights. (The substrate does NOT learn; the algorithm does.)
- **R3 — Sequence prediction (next-symbol over text).** Classical n-gram / VSA+reservoir readout
  (the EQMOD-2 territory; named as established ELM/RLS, not novel). PASS = above-chance next-symbol on
  held-out text, no transformer.
- **R4 — Generative response.** Input prompt → learned continuation (toy "reply"), via R3's predictor +
  the matter-memory holding context. Honest eval: plausible, not understanding.
- **R5 — Honest capability audit.** Quantify how far this is from "human-like" (it will be far): no
  grounding, no reasoning, no generalization beyond the training distribution.

## Expected honest endpoint
A classical statistical communicator (no LLM) with substrate-based memory/IO: it can store, recall, and
predict text plausibly. It is NOT human-like AI and NOT a thinking substrate. If that endpoint is
acceptable as "no-LLM language behavior," the campaign delivers it; if "human-like understanding" is the
bar, no rung reaches it and I will say so at each step rather than imply progress toward a mind.
