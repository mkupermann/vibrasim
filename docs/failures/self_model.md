# Self-Model / Self-Aware Substrate (G16) — What We Simplified

## The shell
The substrate maintains a list of its own pattern_ids and can query
"which patterns do I know". Five conjunction markers operationalize
"access consciousness" loosely inspired by Dehaene & Naccache 2001.

## What a non-thin version requires
- **Meta-representation**: real self-models represent not just "what
  patterns exist" but "what is my confidence in each pattern" and
  "how do my patterns relate to each other". Our self_model is a set
  of IDs, not a structured model.
- **Counterfactual simulation**: a self-aware system should predict
  "what would happen if I did X". This requires an internal forward
  model. We have prediction error (marker 3) but no ability to
  simulate hypothetical actions.
- **Temporal self**: "I was different yesterday" requires autobiographic
  memory. Our substrate has no sense of its own history, only its
  current state.

## What breaks if wrong
The five markers can be trivially satisfied by a system that has no
genuine self-model — just the right variables in the right ranges.
marker_protocol.md acknowledges this explicitly. The negative control
is the discriminating test, and it depends on the markers being
non-trivially correlated. If the simplification makes them trivially
achievable, the entire emergence-detection framework is meaningless.

## When to revisit
When the substrate can learn multiple patterns AND we want it to choose
between them based on internal state rather than external input. That
requires genuine self-modeling, not just pattern counting.
