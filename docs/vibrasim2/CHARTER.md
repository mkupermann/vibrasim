# Vibrasim II — programme charter

**Status:** active prototype programme, replacing further Vibrasim-I experiments.

## One foundational claim

Matter can acquire function only if its organisation changes the field that
supplies the energy required to maintain that organisation.

The causal loop under test is:

`field → absorbed work → local bond turnover → geometry → field`

Vibrasim II does not continue the G-numbered Vibrasim-I ladder. A result here
does not repair or reinterpret a prior NULL.

## Hard constraints

- Every bond has finite lifetime. Persistence is not free.
- Bond formation consumes locally available energy.
- Matter changes field propagation through one universal constitutive law.
- No frequency IDs, pattern IDs, target geometries, repair tables, labels,
  rewards, trained read-outs, neural networks or pretrained components.
- A viewer may display only state emitted by the simulator. Demo frames are
  labelled engineering smoke and are never experimental evidence.
- One open question at a time. Each question is committed before its first run.
- A failed gate closes that stage. It is not repaired by a parameter sweep.
- No result may be called individuation unless bounded multiplicity, turnover,
  persistence and repair all beat the frozen controls.

## Ladder

1. **P0 reciprocal channel:** energy-consistent field↔matter coupling exists
   and its causal direction is detectable.
2. **P1 conditional persistence:** random structures persist only by closing
   their local energy-to-turnover loop.
3. **P2 individuation:** multiple bounded organisations coexist and repair.
4. **P3 organisational memory:** organisation survives material replacement.
5. **P4 functional differentiation:** history builds distinct physical
   transfer functions without labels or dedicated sensors.

Only the next rung may be designed after the current rung receives a verdict.

## Verdict vocabulary

- **PASS:** every registered treatment bar and every control gate holds.
- **NULL:** valid run, clean gates, registered effect absent.
- **INCONCLUSIVE:** an experiment-specific measurement or numerical-validity
  gate prevents interpretation.
- **FAIL:** an experiment-specific protocol or configuration gate fails.

Each committed experiment defines an ordered, exhaustive decision table. That
table overrides this generic vocabulary when it assigns a particular gate.

## Visualisation contract

The live PyVista view is a wireframe observation instrument:

- particles are points;
- supplied bonds are lines;
- supplied field paths are thin lines;
- stable/forming/breaking bonds are cyan/green/orange;
- no inferred surfaces, organisms, smoothing or success animation;
- UI events remain responsive while simulation frames may arrive up to two
  seconds late.
